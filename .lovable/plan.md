

# Atualizar WHATSAPP_PHONE_NUMBER_ID

## Resumo
Atualizar o valor do secret `WHATSAPP_PHONE_NUMBER_ID` no Supabase com o novo ID do número de telefone.

## Ação
Usar a ferramenta de secrets para solicitar ao usuário o novo valor do `WHATSAPP_PHONE_NUMBER_ID`, que será atualizado no Supabase Edge Functions.

## Arquivo impactado
Nenhum arquivo de código precisa ser alterado — apenas o valor do secret será atualizado.
